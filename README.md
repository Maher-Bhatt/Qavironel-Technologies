## Technical Architecture

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite 8
- **Styling:** Tailwind CSS v4 (`@tailwindcss/vite`) with custom theme tokens
- **Routing:** React Router v7 with clean client routing and scroll restoration
- **Typography:** Plus Jakarta Sans & JetBrains Mono
- **SEO & Discoverability:** Dynamic titles, semantic HTML5, Schema.org JSON-LD, Open Graph, `robots.txt`, and `sitemap.xml`

- npm or pnpm


```bash
npm run build
```

### Production Preview
